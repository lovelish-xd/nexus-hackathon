# Nexus Gaming Hackathon

Open index.html in a browser, or run `python -m http.server 4173 --bind 127.0.0.1` from this directory and visit http://127.0.0.1:4173.

Buildless HTML, CSS and JavaScript. No dependencies or account setup. Profile name, bio, avatar URL and MVPicks project URL are editable through Your profile and persisted in browser localStorage. Remote fonts gracefully fall back to system fonts. Project artwork is original typographic illustration, not product screenshots.

This is a private concept requested by the owner. The event, rankings and partner placements are imagined. Riot Games, Epic Games, NVIDIA, Veloren and Mindustry have not been verified as participants or partners. Do not present these placements as actual endorsements or results. Nothing has been deployed.

Project descriptions and outgoing links: https://veloren.net/ and https://mindustrygame.github.io/. MVPicks description supplied by the owner. The hero uses illustrative teams and a product concept, not live match data. No deposits, purchases, wagering, cash conversion, backend authentication or actual judging are implemented.
